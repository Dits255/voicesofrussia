# Недостающие изображения

Сейчас в этих местах стоят временные заглушки `picsum.photos`. Замени их на реальные фото —
просто положи файл в нужную папку и поправь путь в JSON.

Куда класть реальные файлы: `public/articles/<slug>/<имя>.jpg`
Тогда путь в JSON будет `/articles/<slug>/<имя>.jpg` (как у уже готовых статей).
